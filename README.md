## 규칙

- 과제는 `weekNN-이름/` 폴더에 올린다 (NN = 과제를 받은 회차, 예: `week01-이주영/`)
- 폴더마다 [`README-TEMPLATE.md`](./README-TEMPLATE.md) 를 복사해 `README.md` 로 쓴다 — 무엇을 만들었나 · 무엇을 확인했나(캡처나 로그) · 예상과 달랐던 점
- 언어·프레임워크는 자유. 5~7주차 과제는 앞 주 결과물을 이어서 고친다
