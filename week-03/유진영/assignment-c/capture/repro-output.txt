
== 준비: 깨끗하게 다시 띄우기

== ① 멱등: 같은 키로 POST 두 번 → 주문 1건
$ order key-001 ''
HTTP/1.1 201 Created
location: /orders/1
HTTP 201  (0.003399s)

$ order key-001 ''
HTTP/1.1 201 Created
idempotent-replayed: true
HTTP 201  (0.001620s)

$ req http://localhost:8080/orders
HTTP 200  (0.000924s)
[{"id":1,"item":"coffee","qty":1,"createdAt":"2026-11-12T02:25:45.565Z"}]


== ② 500: 핸들러가 예외를 던진다 (앱이 만든 응답)
$ req http://localhost:8080/boom
HTTP 500  (0.001592s)
{"code":"INTERNAL_ERROR","message":"서버 내부 오류","requestId":"2ab93a596c2a716814c234677b97973b"}


== ③ 504: 앱이 4초 걸리는데 nginx는 2초만 기다린다 (nginx가 만든 응답)
$ req 'http://localhost:8080/slow?ms=4000'
HTTP 504  (2.006001s)
<html>
<head><title>504 Gateway Time-out</title></head>
<body>
<center><h1>504 Gateway Time-out</h1></center>
<hr><center>nginx/1.27.5</center>
</body>
</html>



== ④ 504의 함정: 느린 POST가 504로 끝나도 앱은 주문을 만들었다 → 같은 키로 재시도
$ order key-002 '?delayMs=4000'
HTTP/1.1 504 Gateway Time-out
HTTP 504  (2.006742s)

(앱이 뒤에서 끝낼 때까지 3초 기다림)
$ order key-002 ''
HTTP/1.1 201 Created
idempotent-replayed: true
HTTP 201  (0.004104s)

$ req http://localhost:8080/orders
HTTP 200  (0.002819s)
[{"id":1,"item":"coffee","qty":1,"createdAt":"2026-11-12T02:25:45.565Z"},{"id":2,"item":"coffee","qty":1,"createdAt":"2026-11-12T02:25:51.665Z"}]


== ⑤ 502: 앱이 응답 도중 연결을 끊는다 (처리 중 죽은 상황)
