# week03 · 상태 코드와 장애 응답

진단 퀴즈 Q17. 4xx는 요청을 고쳐야 하고 5xx는 서버 쪽이 못 한 것이다. 그중 500은 앱이, 502·504는 앞단의 nginx가 만든다.

## 발표 자료

- [발표 장표 (PDF)](<./상태 코드와 장애 응답.pdf>) — 13장, 15분. 배경 지식 3장(응답의 첫 줄 → 상태 코드의 다섯 반 → 요청이 거쳐 가는 층) → 4xx는 요청 탓, 5xx는 서버 탓 → 자주 쓰는 4xx → 401과 403 → 5xx를 누가 만드나 → 코드별로 먼저 볼 곳 → 1주차 바인딩과 502 → 재시도 규칙 → 에러 응답 설계
- [스터디 노트](<./3주차 발표 스터디 노트 상태 코드와 장애 응답.md>) — 배경 지식부터 장표별 쉬운 설명, 받을 만한 질문, 오늘 순서와 과제 B 데모 순서

처음 보는 사람은 노트의 "먼저 알아 둘 배경 지식"부터 읽으면 됩니다. 핵심은 "브라우저가 받은 상태 코드를 누가 만들었나"입니다.
